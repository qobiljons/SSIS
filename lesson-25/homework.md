# SSIS Package: Incremental Data Loading Using Change Data Capture (CDC)

**Objective:**
Develop an SSIS package to perform incremental data loading using Change Data Capture (CDC). This package will capture and apply insertions, updates, and deletions from source tables to corresponding destination tables, ensuring data consistency and minimizing load times.

---

## **Requirements:**

### **Prerequisites:**

#### **SQL Server Version:**
- Ensure that the SQL Server instance supports CDC, as this feature is not available in all editions.

#### **Permissions:**
- Confirm that you have the necessary permissions to enable CDC on the source database and tables.
